# While loops 
1. The for loop takes a collection of items and executes a block of code once for each
item in the collection. In contrast, the while loop runs as long as, or while, a certain
condition is true.<br>
2. flag : A flag is a Boolean variable used to control loop execution, it decides the condition of the loop.<br>
3. break : It is used to break the loop immediately after this keyword is visible in the code and break exits only the nearest enclosing loop.<br>
4. Continue : When continue is visible in the code, then it skips that particular iteration of the loop and skips the remaining statements in the current iteration and starts the next iteration.<br>
5. While using while loop, be careful of the conditions, sometimes it may lead to infinite looping.<br>
